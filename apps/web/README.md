# apps/web — Application web (React + Vite)

Partagé : la structure est posée par P2 (étape 8 du jalon 1), puis chacun écrit ses pages dans son propre dossier.

- **P1** : catalogue, recherche, réservation, dashboard de gestion des organisateurs.
- **P2** : salle d'attente, connexion (Keycloak), dashboard en direct des organisateurs.

Voir ADR 020.
